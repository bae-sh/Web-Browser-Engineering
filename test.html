아래는 pre 태그 테스트입니다. 공백과 줄바꿈이 그대로 유지되고, 고정폭 폰트로 그려져야 합니다.

def hello(name):
    if name:
        print("Hello,", name)     bold inside pre
    else:
        print("Hello, world!")    italic inside pre

    return    "spaces      preserved"

여기부터는 다시 일반 문단입니다. 자동 줄바꿈이 동작하는지 보려면 창 크기를 줄여 보세요.
